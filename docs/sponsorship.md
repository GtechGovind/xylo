## Account owner setup

Complete account and financial setup directly on GitHub. Do not add payout, tax or identity documents to this repository.

- [ ] Sign in as **GtechGovind**, open [GitHub Sponsors](https://github.com/sponsors) and choose **Get sponsored** for the personal account.
- [ ] Confirm current eligibility and follow GitHub's contact, payout and tax steps. Enable two-factor authentication and review the applicable terms.
- [ ] Add a bio and introduction; the draft below is available to adapt. Feature the [Xylo repository](https://github.com/GtechGovind/xylo).
- [ ] Choose one-time or monthly support and any sponsorship tiers.
- [ ] Submit the application for GitHub's approval and wait for activation.
- [ ] Check the public profile while signed out before adding a direct sponsorship call to action.
- [ ] Verify the funding file on the default branch and check **Settings → General → Features → Sponsorships** if the repository button needs enabling.
- [ ] After activation, replace the pending status in the README and this page with the verified working profile link.

Use GitHub's current instructions for [personal account setup](https://docs.github.com/en/sponsors/receiving-sponsorships-through-github-sponsors/setting-up-github-sponsors-for-your-personal-account) and [repository sponsor buttons](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/displaying-a-sponsor-button-in-your-repository). Preparing the repository file does not complete those account steps.
